# Personal website

This is the source project for the personal website at `https://hytong-claudine.github.io`.

## Build

Open `hytong-claudine.github.io.Rproj` in RStudio and use **Build Website**, or run `rmarkdown::render_site()` from the project directory. The site is authored in R Markdown and uses `_site.yml` for shared navigation and styling.

The introduction, education, email, and GitHub links are filled in. Push the repository to its `main` branch and enable GitHub Pages to publish the site.
